# To-Do List App

A simple To-Do List application built using **HTML, CSS, and JavaScript** to manage daily tasks.

## Features
- Add, edit, and delete tasks
- Set and edit task priorities (High, Medium, Low)
- Mark tasks as completed or pending
- Filter tasks by status
- View task statistics
- Save tasks using Local Storage
- Clear completed tasks or delete all tasks
- Display task creation dates

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start managing your tasks

## Learning Purpose
This project was created to practice JavaScript fundamentals, DOM manipulation, arrays, objects, functions, and Local Storage.
